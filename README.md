# Лабораторная работа №1:

## Описание
Репозиторий содержит решение первой лабораторной работы по интервальному анализу. 
В работе исследуется вырожденность (особенность) интервальных матриц в зависимости от параметра неопределенности $\delta$.

**Решаемые задачи:**
1. Для прямоугольной интервальной матрицы $A_1 \in \mathbb{IR}^{3\times 2}$ (случаи томографии и линейной регрессии) найти диапазон значений $\delta$, при которых матрица содержит точечную матрицу неполного столбцового ранга.
2. Для квадратной интервальной матрицы $A_2 \in \mathbb{IR}^{3\times 3}$ найти диапазон значений $\delta$, при которых матрица становится особенной ($\det A_2 = 0$).
3. Построить точечные вырожденные матрицы $A'_1$ и $A'_2$ для найденных минимальных $\delta$, проверить их принадлежность интервальным матрицам и убедиться в их особенности.
